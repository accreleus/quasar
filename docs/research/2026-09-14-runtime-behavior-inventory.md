## Existing boundary and callers

`ContainerRuntime` is a clonable concrete CLI wrapper, selected by `QUASAR_CONTAINER_RUNTIME` (default `docker`), with an NVIDIA flag. It is not a trait or capability model. Its methods include application launch, image inspection/pull, raw command execution, streaming command construction, ownership-aware sweep/removal, exit wait and log following. The source's Podman “drop-in” wording is not evidence that equivalent semantics have been validated. [Wrapper](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L384).

## Launch and ownership invariants

Application launch validates network and sibling mounts, resolves a managed generation name, checks the persistent owner, and removes only an owned collision. It launches detached with auto-removal and an owner label. Preserve catalog-over-host environment precedence, display/gamescope injection, PUID/PGID environment rather than `--user`, image arguments, per-session Wayland socket-file isolation, audio/udev binds and input devices. Host mount policy rejects sensitive paths, traversal, sockets and dangerous bind options. [Launch](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L765), [mount policy](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/mount_policy.rs#L136).

Hardening/compatibility includes cap-drop ALL plus eight explicit capabilities, PID/shm limits, seccomp/AppArmor selection, privilege-optout policy, optional systempaths/read-only settings, conditional FUSE, NVIDIA GPU requests and driver libraries, DRI device mapping and numeric supplementary groups. Desktop systempaths mode also attempts a privileged root exec to unmount the NVIDIA proc overmount. GPU launch inspects realized device configuration before returning the handle; argument construction alone is insufficient. [Launch options and verification](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L806).

Ownership is a persisted random token beside agent state, with an exclusive inode lease, no-follow opens and malformed-state refusal. Sweep rechecks exact label, allowed prefix and full hex container ID independently of daemon filters. Unlabelled/foreign collisions are preserved. Graceful stop validates ownership by ID; `force_remove` performs that check for managed **names**, but accepts other names/IDs directly for helper/backstop use. A typed interface must explicitly represent these different authorities. [Ownership](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/container_ownership.rs#L1), [removal](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L1243).

## Errors, deadlines and unresolved outcomes

Ordinary commands use 30-second deadlines and concurrently drained stdout/stderr with 256 KiB retention per stream; timeout kills/reaps the CLI child. Assignment pull first inspects locally, treats inspect failure as a reason to attempt pull, and allows 600 seconds. Managed-image presence instead distinguishes definitive missing-image text from daemon failure, preserving existing records on uncertainty. Managed pull/build have output-independent 30/60-minute watchdogs; wire errors are mapped, not raw daemon messages. [Command runner](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L63), [presence](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L1222), [image deadlines](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/images/mod.rs#L39).

Stop defaults to 10-second TERM grace with grace+20-second client deadline, then force-removal. Missing/already-removing cases are tolerated; failures are logged, and the handle's one-shot removed marker is not proof of daemon deletion. Wait is intentionally lifetime-scoped on a detached thread; exit is code/OOM/unknown, with an auto-remove race on OOM inspection. Log following retains 100 lines per generation and allows 750 ms final drain; attaching after auto-removal may lose early-exit logs. [Stop/wait](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L1243), [logs](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L468).

**Open evidence-derived obligations:** client timeout does not establish whether daemon mutation occurred. In `run`, a post-start GPU-inspect transport error propagates before the handle is constructed; caller teardown may later sweep by name, but the method itself does not clean that error path. Audio has a similar pre-handle raw-run uncertainty. Preserve successful semantics while explicitly deciding reconciliation/cancellation/identity rules; do not copy uncertain cleanup behavior as a guarantee or silently retry on another backend. Managed-pull stderr stops reading at 64 KiB, unlike the general drain helper; stdout uses line parsing and an unbounded progress channel. Stream bounds need independent tests. These are static observations, not reproduced failures. [GPU check](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/session/container.rs#L1124), [pull readers](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/node-agent/src/images/mod.rs#L1099).

## Updater boundary

The Go updater already has a separate `Docker.Run(context, argv)` seam, Compose-label discovery, pure planning, persisted apply results, env backup/rewrite, pull/recreate/verify, and bounded failure-log tails. It verifies post-state even after exit zero. Restore distinguishes never-started services, unhealthy agents and potentially migrated control planes. Runtime-interface work must not silently move this ownership into the agent; updater ownership migration is outside map scope. [Executor](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/control-plane/internal/updater/exec.go#L16), [discovery](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/control-plane/internal/updater/discover.go#L1).

## Validation matrix

Existing tests are source evidence, **not newly executed results**. Additions below are proposed gates for implementation.

| Area | Existing coverage | Required migration evidence |
|---|---|---|
| Ownership | Lease restart/isolation/malformed/symlink tests in `container_ownership.rs`; fake-CLI orphan sweep in `container.rs`. | Foreign/unlabelled preservation, ID/name replacement races, duplicate ownership, uncertain create/stop/remove recovery. |

| Images | `images/mod.rs` generation/queue/replay/reconcile/validation tests; progress, errors, disk, build-context modules. | API progress adaptation, local-only image no-op, missing versus unavailable, in-use removal refusal, noisy/silent streams and deadline cleanup. |
| Audio/helpers/GC | Audio argv/socket-layout tests; driver/host-path probe tests; homes-GC fail-closed and filesystem guards; warmup scratch-home test. | Same-directory mount proof, helper cleanup on timeout, silent-audio fallback, GC seeing foreign live mounts, metadata discovery across daemon differences. |
| Updater | [Fake-executable executor tests](https://github.com/accreleus/quasar/blob/5998fc5002cca6d138d30e170b1cfd313d313336/control-plane/internal/updater/exec_test.go#L127), plan/discovery/server/signature tests. | Keep ownership separate; rerun affected integration tests if shared plumbing changes, including zero-exit unhealthy and migration-sensitive restore cases. |

Owner approval still gates promotion from the initiative into develop for this map.
