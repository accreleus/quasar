---
title: Testing and verification
description: The required checks for Go, Rust, web, database, streaming, and deployment changes.
---

The root Makefile is the test interface. Run this for every change:

```bash
make verify
```

It formats, lints, and builds all components, checks shell scripts, and runs the
developer-experience self-tests.

## Checks by change type

| Change | Additional verification |
| --- | --- |
| Go | `make test-go` |
| Go touching the database | `make test-db` as well as `make test-go` |
| Rust | `make test-rust` |
| Web | `make test-web` |
| Before merging to `develop` | `make preflight` |
| Pipeline, encoder, or streaming | Real-session validation on a GPU host |
| Images or deployment | Image contract validation through the canonical build scripts |
| Candidate application image | `make qa IMAGE=<tag> PROFILE=<name> HOST=<role-or-host>` |

A green `make test-go` does not mean the database tests passed. They skip
themselves when no test database is configured. `make test-db` provisions a
fresh throwaway Postgres and runs them for real, and it is not optional after a
migration or a store or query change.

`make test-web` is the typecheck gate for the same reason. Hand-typed `tsc`
invocations have been seen passing here while checking nothing.

## Useful diagnostics

```bash
make diagnose
make diagnose-bundle
```

The bundle is sanitised, stored under the gitignored `.diagnostics/` directory,
and includes a manifest of included and excluded material. Review it before
sharing it.

## Git and generated files

Branches are based on `develop` and merge back to `develop`; promotion from
`develop` to `main` is sign-off gated, because `main` is production. Push the
branch to origin as you work, and pull `develop` before starting a migration.
Two branches both numbering a migration 0070 give you a control plane that
crash-loops on boot.

Do not patch vendored generated clients or generated API types by hand.
Regenerate them from their declared source and keep the source revision recorded
where the repository requires it. A hand edit trips the schema drift check and
gets dropped by the next regeneration anyway.
