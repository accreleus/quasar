## Claim your instance

1. Open Quasar at the HTTPS address chosen during installation, for example `https://192.168.1.50:8443`. An unclaimed instance opens `/setup`.
2. Read the one-time claim token on your server:

```bash
docker exec quasar-control-plane cat /run/quasar/setup-token
```

Use `podman` instead of `docker` for Podman installations, as the account that
runs the engine (root for a rootful Podman install).

3. Enter the token, email, username and password in the Claim step. This creates your administrator account.

<Aside type="caution" title="Warning: restarting rotates the token">
If the control plane restarts before you claim, read the token again.
</Aside>

## Finish setup

The wizard saves your progress, so you can return later.

| Step | Choose or check |
| --- | --- |
| Basics | Keep registration closed, require an invite, or allow open registration. You can change this under People ▸ Invites. |
| Hosts | Check that your GPU host is online and follow any failing [readiness checks](/quasar/troubleshooting/readiness/). Keep the storage path chosen at install unless you intend to reconfigure it. |
| Libraries | Enable Steam and choose who can use it. Quasar prepares the launcher on your hosts. |
| Finishing touches | Optionally add a SteamGridDB key for artwork, enable microphone support and start a library scan. |

Use the address your players will use during setup. **Continue** saves that
origin for streaming; it does not configure DNS or a proxy. An explicitly set
`QUASAR_ALLOWED_ORIGINS` overrides setup's choice; see
[Allowed origins](/quasar/network/reverse-proxy/#allowed-origins).

<Aside type="caution" title="Keep your persistent data">
The `quasar-machine` volume contains the secret key and recovery state. Never
delete it. Back up your [database and homes](/quasar/operations/backup/) to preserve
accounts, games and saves.
</Aside>

Continue with [Set up your game library](/quasar/playing/library/), then
[Play your first session](/quasar/playing/in-session/). You can
[invite other people](/quasar/admin/users/) from the admin area.

## Check your install
