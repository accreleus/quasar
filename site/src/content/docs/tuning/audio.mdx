## Game audio

Audio comes from the session's PulseAudio sidecar, encoded as Opus, on its own
peer connection separate from video. A struggling video stream doesn't drag audio
down. Nothing to configure.

## Fail loudly instead of silently

By default, if the audio sidecar is unavailable, the session continues without
sound. A misconfiguration can then mute every session on a host with only a log
warning. To make the session fail instead:

```bash
QUASAR_AUDIO_REQUIRED=1
```

Recommended on anything you care about. **Admin ▸ Sessions**, session detail,
shows whether audio degraded and why.

The PulseAudio sidecar must come from the same image family as the agent. A
mismatched image can lack PulseAudio and the session runs silent.

## Microphone capture

Three things must all be true:

1. **The administrator enables it** under **Admin ▸ Settings**. Off by default,
   enforced on the server. A launch that asks for a microphone while it's off
   still starts, just without one.
2. **The user turns it on** with the microphone button on the session bar. It is
   off at the start of every session; nothing makes it hot on connect.
3. **The browser grants permission.** This needs HTTPS: plain HTTP can't use the
   microphone.

A live microphone shows a persistent indicator that can't be dismissed or hidden.

Inside the container the microphone appears as a normal capture device, so Steam
and games offer it. The format is fixed at stereo Opus, 48 kHz, because Chrome
rejects anything else.

## The host kill switch

```bash
QUASAR_MIC_DISABLED=1
```

Disables microphone capture on this host's agent, overriding the instance setting.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| No sound at all | Session detail for degraded audio, then that the sidecar image matches the agent image. Set `QUASAR_AUDIO_REQUIRED=1` so the next one fails visibly. |
| Microphone button missing | The instance setting is off. |
| Button present but does nothing | Browser permission denied, page not on HTTPS, or input is captured (release capture first). |
| Sound in some apps only | The app picked a different output device inside the container. That's the app's own setting. |
