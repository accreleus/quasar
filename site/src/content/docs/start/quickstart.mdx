Install Quasar on one Linux GPU server with its own managed database. Check the
[requirements](/quasar/start/requirements/), then choose your engine, GPU and storage.
For a split control plane, follow [Docker installation](/quasar/install/docker/).
To expand an existing instance, use its [Add GPU host command](/quasar/install/second-host/).
