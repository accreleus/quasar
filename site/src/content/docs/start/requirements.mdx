## The host machine

| | Requirement |
| --- | --- |
| OS | Linux with systemd. Docker Desktop on macOS and Windows can't carry the stream. |
| Container engine | Docker Engine 20.10+ or Podman. See [Engine profiles](/quasar/start/engine-profiles/). |
| Disk | About 20 GB free where the container engine stores images, plus room for games and saves. A control-only machine needs much less. |
| CPU and RAM | Modest: the GPU does the encoding. Tested on 8 vCPU and 32 GB. |
| GPU | See [GPU](#gpu). |

Compose isn't needed. Quasar starts its own containers.

| Stack manager | Status |
| --- | --- |
| Plain Docker or Podman | Supported |
| Dockge, Arcane | Supported |
| Unraid (`docker run`) | Supported |
| Portainer, Kubernetes | Not supported |

One Quasar installation per container engine.

### GPU

| Vendor | Encoder | Status |
| --- | --- | --- |
| AMD | Vulkan Video | Verified |
| NVIDIA | Vulkan Video | Verified |
| Intel | VA-API | Untested |
| None | openh264 (software) | Works, too slow to play on |

**NVIDIA** needs the full driver (not CUDA-only) and the NVIDIA Container Toolkit:

```bash
sudo nvidia-ctk runtime configure
sudo systemctl restart docker
```

### NVIDIA on Unraid

See [Install on Unraid](/quasar/install/unraid/#nvidia).

### Kernel

`/dev/uinput` must exist (Quasar's virtual keyboard, mouse and gamepads):

```bash
sudo modprobe uinput
echo uinput | sudo tee /etc/modules-load.d/uinput.conf
```

### One sysctl

Raise the UDP send buffer on every GPU host. Without it, keyframes get dropped and
the stream throttles as if the network were bad:

```bash
echo 'net.core.wmem_default=2097152' | sudo tee /etc/sysctl.d/99-quasar.conf
sudo sysctl --system
```

[Host preparation](/quasar/install/docker/#prepare-the-host) and the quick start's scripts
do this and the `uinput` step for you.

### Firewall

The node agent uses the host network, so a default-deny firewall must allow its
WebRTC UDP. See [Ports and endpoints](/quasar/reference/ports/#firewall).
SELinux can stay enforcing.

## The client device

A recent Chrome or Chromium. Firefox and Safari are untested
([Browser support](/quasar/playing/browsers/)).

The page must be served over HTTPS for gamepads, keyboard lock and the microphone.
Quasar makes its own certificate, so this is handled
([HTTPS and certificates](/quasar/network/https/)).

## Network

The client must reach the GPU host directly: same LAN or a VPN. The stream doesn't
go through a reverse proxy. See [Reaching Quasar remotely](/quasar/network/remote-access/).
