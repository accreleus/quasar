## Your server

| Component | Requirement |
| --- | --- |
| OS | Linux. |
| Container engine | Docker Engine 20.10+ or Podman. See [Container engines](/quasar/start/requirements/#container-engines) for current support status. |
| Disk | Allow about 20 GB for container images, then additional space for installed games, saves and user files. Check where your engine stores images as well as your homes disk. |
| CPU and RAM | Quasar's services have modest overhead. Size the host for the games and number of simultaneous sessions you intend to run; the GPU handles video encoding. The 8 vCPU / 32 GB test host is a test configuration, not a minimum. |

Docker Desktop on macOS or Windows, and WSL, are unsupported.

## Container engines

Quasar runs on Docker and Podman in rootful or rootless mode. Rootless modes and
rootful Podman remain experimental.

<EngineProfiles />

**Supported:** tested end to end. **Experimental:** tested, with release validation
still incomplete. Tests cover rootful Docker with AMD/NVIDIA, and Podman/rootless
on Fedora uCore and Workstation; this does not validate every distribution.

### What’s the difference between rootful and rootless?

<Aside type="note" title="Rootful and rootless">
**Rootful** runs the engine as root; access to its socket gives control of the machine.
**Rootless** runs under an ordinary account with reduced privileges and needs extra
account and device setup. See [Rootless installation](/quasar/install/rootless/).
</Aside>

The documented [Podman](/quasar/install/podman/) and rootless installation paths
require systemd; Quasar on rootful Docker does not. Run one Quasar installation per
engine. Compose, Dockge and Arcane can manage its seed; Portainer and Kubernetes
are unsupported.

## Network

**Your browser must reach each GPU host directly over your LAN or VPN.** A reverse
proxy can carry the web app and API; it cannot carry the game stream.

The UDP range is chosen by Linux: check `cat /proc/sys/net/ipv4/ip_local_port_range`
on the GPU host. A default-deny firewall must allow it even when login works.
See [Firewall rules and custom ports](/quasar/reference/ports/#firewall) and
[Remote access](/quasar/network/remote-access/). Optional UDP buffer tuning is in

## Your client

Use recent **Chrome or Chromium**. Firefox and Safari are untested; see
[Browser support](/quasar/playing/browsers/).

HTTPS is required for gamepads, keyboard lock and the microphone. The install
steps configure Quasar's certificate; see [HTTPS and certificates](/quasar/network/https/)
for trusting it or using a reverse proxy.
