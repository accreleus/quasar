---
title: Browser support
description: Which browsers work and why HTTPS is required.
---

Use a recent Chrome or Chromium-based browser, such as Edge or Brave. Chrome
is the tested client; Firefox and Safari remain untested.

Keyboard Lock and controller support are tested with Chrome. Use HTTPS to enable
these features and microphone capture.

## HTTPS is not optional

| Feature | Without HTTPS |
| --- | --- |
| Gamepad support | Controllers are not detected. |
| Keyboard Lock | Escape leaves fullscreen instead of reaching the game. |
| Microphone | Cannot be enabled. |

The default install serves HTTPS on port 8443 with a self-signed certificate.
Accept the browser warning once. See [HTTPS and certificates](/quasar/network/https/).

## Codec compatibility

Quasar checks the codecs your browser reports at login. The available codecs
depend on the browser, operating system and hardware; AV1 is not guaranteed on
every Chromium device. HEVC requires compatible OS hardware decoding.

See [Codecs](/quasar/tuning/codecs/) for the selection rules and compatibility
limits. Browser sessions use constrained-baseline H.264 automatically.

## Mobile and tablets

Touch devices get an on-screen menu button and touch input is forwarded. Most
games need a paired controller to be playable.

## Nothing to install

No launcher, extension or client binary is needed. The browser is the supported
client.
