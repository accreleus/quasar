## Be clear about what this is

It finds **installed** games in the Steam container's library folder. Owned but
uninstalled games don't appear; install them through the Steam launcher app and
they show up on the next scan.

It does not:

- check that a launch got past Steam's own interface,
- find games on a second Steam library disk,
- support more than one Steam account per user,
- switch games inside a live session.

## Turning it on

Use the switch under **Admin ▸ Settings**, or step four of the first-run wizard.
This installs the Steam image on your hosts, creates its runtime preset, and adds a
launcher app granted to everyone.

The Steam source shows under **Admin ▸ Library ▸ Sources** either way.

## Requirements

- **Network access.** The runtime preset needs `network: bridge` (the shipped
  preset sets it). Without it Steam exits and the session fails with a misleading
  media-path error.
- **A managed-home root on each host**, set under **Admin ▸ Fleet ▸ Hosts**.
- **Installed games.** Open the Steam launcher app, log in, install something.

## Scanning

Scans run every 360 minutes by default. Set `QUASAR_LIBRARY_SCAN_INTERVAL` (in
minutes; `0` disables scheduled scans). **Admin ▸ Library ▸ Sources** can scan now.

## Steam-derived apps

Each game becomes a normal app using the Steam image, launched at that title.
Entitlements, tiers and artwork work as for any app. Updating the Steam image
affects all of them.

## Only Steam, for now

Steam is the only library provider. Add anything else (Heroic, RomM and so on) as
an app by hand.
