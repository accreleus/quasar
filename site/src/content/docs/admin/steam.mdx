## What discovery finds

It finds **installed** games in the Steam container's library folder. Owned but
uninstalled games don't appear; install them through the Steam launcher app and
they show up on the next scan.

It does not:

- check that a launch got past Steam's own interface,
- find games on a second Steam library disk,
- support more than one Steam account per user,
- switch games inside a live session.

## Turning it on

1. Enable Steam library discovery under **Admin ▸ Settings**.
2. Wait for Quasar to install the Steam image and create its launcher app.
3. Open the launcher, sign in to Steam and install a game.
4. Scan under **Admin ▸ Library ▸ Sources**, or wait for the scheduled scan.

The launcher is available to everyone. Installed games appear as separate tiles;
see [Set up your game library](/quasar/playing/library/).

## Requirements

- **Network access.** The runtime preset needs `network: bridge` (the shipped
  preset sets it). Without it Steam exits and the session fails with a misleading
  media-path error.
- **A managed-home root on each host**, set under **Admin ▸ Fleet ▸ Hosts**.
- **Installed games.** Open the Steam launcher app, log in, install something.

## Scanning

Scans run every 360 minutes by default (`6h`, the admin setting under **Admin ▸
Library ▸ Steam ▸ Discovery settings**). Set `QUASAR_LIBRARY_SCAN_INTERVAL` as a
Go duration such as `360m` or `6h` to override it; a bare number fails startup,
and `0` disables discovery entirely regardless of the admin master switch.
**Admin ▸ Library ▸ Sources** can scan now.

## Steam-derived apps

Each game becomes a normal app using the Steam image, launched at that title.
App access, quality tiers and artwork work as for any app. Updating the Steam image
affects all of them.

## Only Steam, for now

Steam is the only library provider. Add anything else (Heroic, RomM and so on) as
an app by hand.
