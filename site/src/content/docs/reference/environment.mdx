Deployment and process settings are supplied through environment variables in
`deploy/.env`. Instance settings and many host settings are persisted and
editable through the admin UI; where both exist, the table notes whether the
environment is a seed, fallback, or authoritative override.

Many node agent settings can also be overridden per host from Admin, Fleet, Hosts,
Settings, which is easier than editing a file on every machine.
Precedence runs: per-host override, then agent environment, then catalog default.

<Aside type="note" title="This is the practical subset">
The full catalogue including debug and development settings lives in
`docs/configuration.md` in the repository. Anything not listed here is either
internal or something you should not change without a measurement.
</Aside>

## Required

| Variable | Notes |
| --- | --- |
| `DATABASE_URL` | Postgres connection string. |
| `ENROLLMENT_TOKEN` | Shared secret agents present on first contact. Must match on control plane and every agent. |
| `CONTROL_PLANE_URL` | Agent side. WebSocket URL of the control plane. |
| `POSTGRES_PASSWORD` | Compose. Generated on a fresh install. |

The release install has you generate these values before first boot. The
source-build `redeploy.sh` path generates missing secrets and never overwrites
existing ones.

`CONTROL_PLANE_URL` and `ENROLLMENT_TOKEN` can also be supplied together as
one paste: mint `QUASAR_ENROLLMENT` from Admin, Fleet, Enroll host on an
existing host and set only that on the new one. See below.

## Setup and identity

| Variable | Default | Purpose |
| --- | --- | --- |
| `BOOTSTRAP_ADMIN_EMAIL` | unset | Provisions the first admin at boot. Idempotent. |
| `BOOTSTRAP_ADMIN_USERNAME` | unset | With the above. |
| `BOOTSTRAP_ADMIN_PASSWORD` | unset | With the above. Set all three or none. |
| `REGISTRATION_MODE` | `closed` | Seeds the registration mode on first boot of a fresh database only. The admin UI is authoritative afterwards. |
| `PUBLIC_BASE_URL` | unset | Canonical public URL for invite links and proxied signaling. Set it when a proxy rewrites `Host`; otherwise the public host can be derived from forwarded or request headers. |
| `NODE_NAME` | hostname | Agent side. A stable identity for this host. |
| `QUASAR_ENROLLMENT` | unset | Agent side. The one-paste second-host string from Admin, Fleet, Enroll host: a `wss://` control-plane address, the certificate fingerprint the agent pins, and a single-use hour-long token, together. `CONTROL_PLANE_URL` / `ENROLLMENT_TOKEN`, if also set, override the values inside it. |

## Secrets

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_SECRET_KEY` | unset | Base64 of 32 bytes. Encrypts credentials stored through the admin UI. **Back this up. It is not recoverable.** |

## TLS and access

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_TLS` | `auto` | `auto` or `off`. |
| `QUASAR_TLS_ADDR` | `:8443` | HTTPS listener. |
| `QUASAR_TLS_HOSTS` | unset | Comma-separated names and IPs the generated certificate should cover. **Required for LAN access.** |
| `QUASAR_TLS_CERT` | unset | Your own certificate. Set with the key or not at all. |
| `QUASAR_TLS_KEY` | unset | Your own key. |
| `QUASAR_TLS_DIR` | `/var/lib/quasar-control/tls` | Where the generated certificate is kept. |
| `QUASAR_HTTP_REDIRECT` | `auto` | HTTP to HTTPS redirect for browser routes. |
| `QUASAR_ALLOWED_ORIGINS` | unset | Authoritative override for signaling WebSocket origins. Leave unset to manage them in Admin, Settings; with neither source set, same-origin is allowed. `*` is rejected. |
| `QUASAR_TRUSTED_PROXIES` | unset | Proxy IPs or CIDRs whose forwarded client-address headers are trusted. Empty ignores forwarded addresses. |
| `LISTEN_ADDR` | `:8080` | HTTP listener. |
| `CONTROL_PORT` | `8080` | Compose. Host port for HTTP. |
| `QUASAR_TLS_PORT` | `8443` | Compose. Host port for HTTPS. |
| `CONTROL_PLANE_FINGERPRINT` | unset | Agent side. Manual pin of the control plane's certificate (the SHA-256 it logs at startup), for rotating without re-enrolling. Overrides the fingerprint carried in `QUASAR_ENROLLMENT`. |
| `QUASAR_ALLOW_PLAINTEXT_AGENT` | unset (off) | Agent side. A `wss://` `CONTROL_PLANE_URL` is pinned to that fingerprint and just works; a `ws://` URL to anything but localhost is refused unless this is `1`, since the enrollment token and node secret would cross it in cleartext. |

## Storage

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_HOME_ROOT` | unset | Lowest-priority managed-home root fallback. A host with no effective root cannot launch a managed-home app. Fresh `redeploy.sh` installs seed `/var/lib/quasar/homes`. |
| `QUASAR_STORAGE_PROVIDER` | `auto` | `auto` or `local`, which both select mount-path storage. `volume` was removed and is rejected. |
| `QUASAR_ARTWORK_DIR` | `/var/lib/quasar-control/artwork` | Artwork cache. Needs a persistent volume. |
| `QUASAR_ARTWORK_PROVIDER` | `steamgriddb` | `steamgriddb` or `none`. |
| `QUASAR_STEAMGRIDDB_API_KEY` | unset | Or set it through the admin UI, which takes precedence. |

## Encoding

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_ENCODER` | unset, auto-detect | AMD and NVIDIA default to `vulkan`, Intel to `va`, and no GPU to `openh264`. Explicit `va`, `nvenc`, `vulkan`, or `openh264` wins. |
| `QUASAR_RENDER_NODE` | unset | Optional DRM render-node pin. Prefer a `/dev/dri/by-path/` path when pinning a multi-GPU host. |
| `QUASAR_CUDA_DEVICE` | `0` | NVENC device index on a multi-GPU host. |
| `QUASAR_ZEROCOPY` | off | Full zero-copy on the VA path. |
| `QUASAR_GOP` | `60` | Frames between keyframes. |
| `QUASAR_SLICES` | `8` | H.264 slices per frame. Supported by Quasar's patched Vulkan H.264 encoder as well as applicable vendor paths. |
| `QUASAR_TARGET_USAGE` | `6` | VA speed against quality, 1 to 7. |
| `QUASAR_QUEUE_BUFFERS` | `3` | Encode queue depth. |
| `QUASAR_VULKAN_H264` | on | Set `0` to move H.264 off Vulkan when a vendor fallback exists. |
| `QUASAR_VULKAN_HEVC` | on | Set `0` to move HEVC off Vulkan when a vendor fallback exists. |
| `QUASAR_VULKAN_AV1` | on | Set `0` to move AV1 off Vulkan when a vendor fallback exists. |
| `QUASAR_VULKAN_MAX_SESSIONS` | `2` | Concurrent Vulkan encode sessions per GPU. |
| `QUASAR_REQUIRE_HW_RENDER` | `1` | Fail a session that falls back to software rendering. |

## Adaptive bitrate

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_ABR_MODE` | `smooth` | `smooth`, `protective` or `off`. |
| `QUASAR_ABR` | `1` | Legacy on and off. `0` maps to `off`. |
| `QUASAR_ABR_FLOOR_KBPS` | unset | Explicit floor. |
| `QUASAR_ABR_FLOOR_RATIO` | `0.3` | Floor as a fraction of the tier bitrate. |
| `QUASAR_ABR_LADDER` | on in `smooth` | Encoder speed escalation under saturation. |
| `QUASAR_ABR_LADDER_RESOLUTION` | off | Opt-in external-resolution rung. Requires `smooth`; applies to the next session. |
| `QUASAR_ABR_LADDER_FPS` | off | Opt-in 120-to-60 FPS rung. Requires `smooth`; applies to the next session. |

Roughly fifteen further hysteresis settings exist. Every default matches the
value that used to be hardcoded. Do not change them without a measurement.

## Updates and releases

The updater service, on every host that has one:

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_UPDATER_IMAGE` | `quasar-updater:latest` | The updater's image. A tag, not a digest, on purpose: the updater applies a release, so it is not one of the images a release moves. Registry installs set `ghcr.io/accreleus/quasar/quasar-updater:latest`. |
| `QUASAR_STACK_DIR` | a sentinel that refuses to work | The stack directory's absolute **host** path, mounted into the updater at that same path. Required. The updater rebuilds its compose invocation from its own container labels, which record host paths. Left unset it refuses to serve and says which label it could not resolve. |
| `QUASAR_DOCKER_SOCKET` | `/var/run/docker.sock` | Host path of the container-runtime socket mounted into the updater. Rootless Podman: `/run/user/<uid>/podman/podman.sock`. |
| `QUASAR_UPDATER_ALLOWED_NAMESPACES` | `ghcr.io/accreleus/quasar` | Comma-separated registry namespaces this host will pull platform images from, matched on path segment boundaries. Anything outside is refused before a byte is pulled. Unset or blank means the project's own namespace, never "allow nothing" and never "allow everything"; to lock a host down, name a namespace nothing matches. |
| `QUASAR_UPDATER_WAIT_TIMEOUT_S` | `300` | How long the updater waits for a recreated service to become healthy. A request may name its own value. |

Release detection, on the control plane:

| Variable | Default | Purpose |
| --- | --- | --- |
| `QUASAR_PLATFORM_RELEASE_REPO` | `accreleus/quasar` | The `owner/name` repository whose GitHub Releases the detection job reads. Point it at a fork to follow that fork's releases. Set it to the **empty string** to turn detection off entirely: every run is skipped, no outbound request is made, and the Releases page reports nothing available. |
| `QUASAR_PLATFORM_RELEASE_TOKEN` | unset | Optional bearer token for the release listing and asset download. A public repository needs none; set it for a private fork or to lift the unauthenticated rate limit. Never logged. |
| `QUASAR_PLATFORM_REGISTRY` | `ghcr.io` | The registry the two platform component images are published to. Used only on the `edge` channel, which resolves a branch tag to a digest; `stable` reads a release manifest and never touches a registry. This host is added to `QUASAR_IMAGE_REGISTRY_HOSTS` automatically. Anonymous pull only. |
| `QUASAR_PLATFORM_RELEASE_DETECT_INTERVAL` | unset; the job defaults to `168h` | Overrides the `platform.release_detect` schedule, which is otherwise weekly in a one-hour window opening 02:00 Monday UTC. A Go duration, authoritative over the admin Jobs page while set; `0` stops the job being scheduled at all. "Check now" bypasses the window either way. |

<Aside type="note" title="The channel is not an environment variable">
Which channel an instance follows, and which branch `edge` follows, are instance
settings edited on the Releases tab. See [Updating
Quasar](/quasar/admin/releases/#channels).
</Aside>

## The host sysctl

Not an environment variable, but required on every host that serves media:

```bash
sudo sysctl -w net.core.wmem_default=2097152
echo 'net.core.wmem_default=2097152' | sudo tee /etc/sysctl.d/99-quasar.conf
```
